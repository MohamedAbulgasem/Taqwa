# Settings Widgets screen and About Taqwa profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settings gains a Widgets row and screen (background on top, previews, add or illustrated steps), Appearance keeps the theme alone, and About Taqwa becomes the profile page holding Rate, Share and Attribution.

**Architecture:** Compose Multiplatform screens in `shared/.../feature/settings/`, in the existing settings idiom. The widget logic already exists (`WidgetPlacementSource`, `WidgetPinRequester`, `widgetOffer`, `WidgetAddPath`); the new screen consumes it. Decisions that can be pure functions are pure functions with commonTest tests; the screens themselves are verified on an emulator and the iPhone simulator.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform, composeResources strings (7 languages + `values-in` twin), Gradle (JDK 21), `scripts/test.sh`, `scripts/ios-build.sh`, `scripts/check-strings.sh`, `tools/sync-indonesian.py`.

**Spec:** `docs/superpowers/specs/2026-10-30-settings-widgets-about-design.md` (read it whole; the design canvas it names is the visual reference, its artboard sources are in the session scratchpad `settings-design/project/*.dc.html`).

## Global Constraints

- Leave `SettingsScaffold`'s signature and scroll modifier untouched (another branch edits them).
- Privacy promise strings (`about_stays_*`, `about_online_*`, `about_nothing_*`) and every location string: keys and texts untouched; the online row keeps `about_online_body` with `// TODO(watch-companion merge): aboutOnlineBody(isIosPlatform)`; no new key starts with `about_online_body`.
- New string keys: prefixes `settings_widgets`, `widgets_`, `about_` only; added as ONE block right after the existing `about_`/`settings_` keys in every `values*/strings.xml`, never at the file's end; `values-in` regenerated by `tools/sync-indonesian.py`.
- Root screen: keep an App group and an About group with nothing between them (a Watch section will go there later).
- No widget runtime change (widgetcore, Glance, WidgetKit), no onboarding change.
- Commits: identity Mohamed Abulgasem <mohamed.abulgasem.ly@gmail.com>, NO Co-Authored-By trailer; never push.
- Devices: Android emulator on port 5572+ (never 5558, 5562, 5564–5568), AVD `Pixel_8_Pro` only if no running emulator uses it, stopped by serial; an own iPhone simulator device; never the watch simulators or the plugged-in phone.

## Review Focus

1. Placement not yet read on first composition → root row shows no value and the Widgets cards show neither a check nor a button (no flash of a wrong state).
2. A launcher that refuses the pin (`requestPin` false) → that card shows the steps panel at once, announced, and stays so across rotation (saved state).
3. Both widgets missing on iPhone → steps expanded on the first card only, a "Show me how" row on the second.
4. Longest labels (Bengali, Urdu, Indonesian "Tembus pandang") in the background control at 360 dp and font scale 1.3 → complete, no ellipsis.
5. Right-to-left (Arabic, Urdu) → step numbers, link glyphs and the About pills mirror like the rest of Settings; share and star glyphs do not.
